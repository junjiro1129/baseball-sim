使い方

PCでの基本の流れ
① スプレッドシートで出力 → ② Excel や Google スプレッドシートで編集 → ③ スプレッドシートを読み込み → ④ この画面で確認・微調整 → ⑤ JSONを書き出す → アプリの「データ読込」で取り込み。

タブの構成
「はじめに」「リーグ編成」のほかは、チーム1 チーム2 … と通し番号で並びます。 この番号は「リーグ編成」タブの番号の列と対応しています。

チーム名と略称は「リーグ編成」タブだけで変えます
各チームのタブの1〜2行目は数式で、「リーグ編成」の内容が自動で表示されます。直接は編集できません。 編集箇所が1か所だけなので、食い違いが起きません。

リーグ所属も「リーグ編成」タブで決まります
Aリーグ・Bリーグの2つの表があり、どちらにあるかで所属が決まります。 移したいときはその行ごと（番号を含めて）上下の表の間で移動してください。 番号で引く数式にしてあるので、行を動かしても各チームタブの表示はずれません。 並び順もこの表のとおりになります。

打順はドロップダウンで選びます
野手9行の「打順」欄から1〜9を選んでください。
入れ替えの途中で同じ番号が重なることは避けられないため、重なっている間はそのセルが赤く表示されます。 入れ替えが終われば色は消えます。赤が残ったまま読み込むと、上からの並び順を打順として扱います。

守備位置と役割は行で決まっています
野手は上から C 1B 2B 3B SS LF CF RF DH の9行＋控え4行。 投手は SP5行・RP6行・SU1行・CL1行。
この形にしてあるので、守備位置の重複も抜けも、投手の役割構成の崩れも起こりません。人数も13人ずつで固定です。

チームを増やす・減らす
この画面の「チーム追加」「削除」で増減させ、出力し直すのが確実です。
表計算側で増やす場合は、チームのタブを複製してタブ名を チーム◯（次の番号）に変え、 「リーグ編成」にも同じ番号の行を追加します。減らす場合はタブと行の両方を消します。

グレーの欄が編集できないとき
守備位置・役割・人数を守るため、チームのタブに保護をかけています。白い欄は普通に編集できます。 構造ごと変えたい場合は Excel の「校閲 → シート保護の解除」で外せます（パスワードはありません）。

保存形式
.xlsx のまま保存してください。CSVで保存するとタブの構成が失われます。 Google スプレッドシートの場合は「ファイル → ダウンロード → Microsoft Excel (.xlsx)」です。

能力値の目安
1〜99の整数で、35〜95が標準の範囲です。「能力をランダム生成」で強い／標準／弱いの3水準から一括生成もできます。

注意：アプリでの読み込みはリーグ戦を始める前に行ってください。 ペナント進行中に読み込むと、順位表や日程がチーム構成と食い違います。アプリ側でリセットしてから取り込むのが確実です。
